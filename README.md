# 📖 Course Description

Software engineering is not only about writing code—it is about building **reliable, maintainable, efficient, and high-quality software**.

This course introduces the concepts of **Software Measurements and Metrics**, enabling students to quantitatively evaluate software products, software processes, and software projects.

Throughout this course, students will learn how software organizations measure:

- Software Size
- Software Complexity
- Software Quality
- Software Reliability
- Testing Effectiveness
- Productivity
- Process Maturity

and use these measurements to make better engineering decisions.

---

# 🎯 Course Learning Outcomes

By the end of this course, students will be able to:

- Measure software using standard software metrics
- Analyze software complexity and quality
- Apply testing and reliability metrics
- Evaluate software process maturity
- Interpret software metrics for decision making
- Understand industrial practices followed in modern software companies
